# Contributing

TokMesh Lite is both a useful validator and a learning repository. Keep changes small, explained, and tested.

1. Create a focused branch.
2. Add or update a fixture that demonstrates the behavior.
3. Run formatting, Clippy, tests, and documentation locally.
4. Explain both the Rust concept and the data-product behavior in the pull request.

Do not add infrastructure, authentication, a web interface, or a plugin framework to this repository. Those belong to later TokMesh stages.
